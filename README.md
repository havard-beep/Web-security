# Projeto HTML/CSS - Página de Curso

Projeto estático criado a partir dos prints enviados, com HTML e CSS separados.

## Arquivos

- `index.html`
- `styles.css`
- `assets/` com imagens SVG locais

## Como abrir

Abra o arquivo `index.html` no navegador.

## Observação

Este material é uma réplica visual para estudo. Para uso comercial ou publicação, altere nomes, marcas, textos e elementos protegidos por identidade visual.
